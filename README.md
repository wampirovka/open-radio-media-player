# Open Radio & Media Player

Open-source Android audio player combining:

- Internet radio
- Local music
- Background playback
- MediaSession / system controls
- Radio Browser integration
- Custom radio streams
- Favorites
- Playlists

## Current milestone

v0.1.0 - playback architecture prototype.

The official Fajn Rock Music stream endpoint is intentionally not guessed in source code. It will be filled after verifying the current official stream URL.

## Tech

- Kotlin
- Jetpack Compose
- AndroidX Media3 / ExoPlayer
- MediaSessionService

## Build

Open the repository in Android Studio and run the `app` configuration.
